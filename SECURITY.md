# Security

Report a security hole privately, not in a public issue.

## How to report

Open a private report on the Security tab of this repository: [report a vulnerability](https://github.com/tollgate-ai/tollgate-ai.github.io/security/advisories/new). Say what you found and how to reproduce it.

For a hole in Tollgate itself, report it to [tollgate-ai/tollgate](https://github.com/tollgate-ai/tollgate/security/advisories/new).

## Versions

Only the page that is live gets fixes.
